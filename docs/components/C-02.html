Scenario Validator

Design › Scenario Validator

ResponsibilityReject a scenario before the run if it cannot run correctly and safely in the chosen stage.
Tool category«tool» Schema and operating-domain checker
OwnerMember 1
GroupAuthoring & control
DeploymentDesktop; in-vehicle test computer in ViL
ProvidesValidation report
RequiresParsed scenario, Backend adapter interface

Description

It checks that the files are valid, that the chosen simulator supports every feature used, and that road type, speed and weather fall inside the stack's operating domain. For vehicle tests it also checks the minimum gap for new actors and that only virtual-stream faults are used.

Key behaviors

  • Reports every broken rule, not just the first.
  • Operating-domain limits come from reviewed configuration, not from the scenario.

Stage variation

All checks in every stage; vehicle rules only for ViL.

Failure behavior

If it cannot decide, the run does not start.

Requirements satisfied (6)

  • Open, simulator-independent formats (supporting)
  • Pre-run validation and ODD check (primary)
  • One-action run start (supporting)
  • Start injection only when the stack is ready (supporting)
  • No pop-in actors (supporting)
  • Vehicle-test faults limited to virtual streams (primary)

Related decisions

  • Simulator-agnostic scenario format
  • Validate before the run
