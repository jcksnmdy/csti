Description

Scenes and scenarios are built in RoadRunner. RoadRunner exports the road as OpenDRIVE and as glTF (the format AURELION loads) and the scenario as ASAM OpenSCENARIO; the exported files, not the tool, are the source of truth. Scenes can be rebuilt from the team's drive data (camera, LiDAR, GPS), and scenarios generated from recordings or as variations. The base set is steady follow, lead-vehicle braking, cut-in and curve keeping, each parameterized so one file covers a family of tests.

Key behaviors

  • Positions are in road or ego-relative coordinates, never a simulator's own.
  • Every run traces back to one scenario file and its parameters.
  • The base set doubles as onboarding templates.

Stage variation

Identical in every stage.

Failure behavior

A file that does not parse produces no scenario, never a partial one.

Requirements satisfied (4)

  • Single scenario definition (primary)
  • Same scenario in every stage (primary)
  • Open, simulator-independent formats (primary)
  • New-user onboarding time (primary)
