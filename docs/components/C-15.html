Monitoring & Operator View

Description

The operator view in the car shows run state, the stack's status (feature states, faults, touring mode) and the virtual actors around the vehicle, with an always-visible stop button. The engineer view shows campaign progress and verdicts.

Key behaviors

  • Status is labeled in text, not only by color.

Stage variation

Engineer view everywhere; operator view in HIL and ViL.

Failure behavior

If the operator view freezes, injection stops.

Requirements satisfied (7)

  • One-action run start (supporting)
  • Live operator view (ViL) (primary)
  • Engineer progress view (primary)
  • Always-visible stop control (primary)
  • Status not shown by color alone (primary)
  • Start injection only when the stack is ready (supporting)
  • Stop injection on operator command (supporting)

Related decisions

  • CSTI has no safety authority
  • Run-lifecycle state machine
