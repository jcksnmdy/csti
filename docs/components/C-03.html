Description

A run profile (MiL, PiL, HIL, ViL or shadow) names the simulator, sensor fidelity, where each part runs and the clock. Changing stage means changing profile. Campaigns repeat a scenario over a parameter sweep without supervision. It listens to the stack's status and stops injection when the stack reports a fault or override, or the operator presses stop.

Key behaviors

  • Drives the run lifecycle shown on the design page.
  • A crashed run is marked failed and the campaign continues.
  • Starts injection only when the stack reports no fault and the operator confirms the driver is ready.

Stage variation

Same code in every stage.

Failure behavior

If it crashes, injection stops; the stack's own safety chain is unaffected.
