Run Evaluator

Design › Run Evaluator

ResponsibilityTurn each recording into a pass or fail verdict and roll verdicts into reports.
Tool category«tool» CI test runner and scenario scoring
OwnerMember 1
GroupAuthoring & control
DeploymentDesktop and CI server
ProvidesVerdicts and reports
RequiresParsed scenario, Recording

Description

Unit, integration and base-scenario tests run on every change. Scenario runs are scored on gap, time-gap error, minimum time-to-collision, jerk and lateral offset. When a scenario injects a fault, it also checks the stack's response: fault raised, defaults sent, driver alerted.

Key behaviors

  • Scores from the recording, so a live run and its replay get the same verdict.
  • Stopped or invalid runs never pass.

Stage variation

Same in every stage; vehicle runs are scored on virtual actors only.

Failure behavior

A run that cannot be scored is flagged, never passed.

Requirements satisfied (3)

  • Unattended campaigns (supporting)
  • Verdicts linked to recordings (primary)
  • Record stack faults and state changes (supporting)

Related decisions

  • Record everything
