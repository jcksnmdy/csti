Recording & Replay

RequiresActor states, Ego state, Fault schedule, Stack interface contract, Operator commands, Stack status, Shadow would-have commands

Description

On the desktop, topics go into MCAP files. On the bench and vehicle, a separate Intrepid data logger records the run and the CAN bus and uploads the logs to the cloud, where CSTI pulls them later for replay and scoring. Real sensor data is recorded too, so a vehicle run can be replayed on the desktop. It also records every stack fault, state change, override and interlock default. A gap in the recording marks the run invalid.

Key behaviors

  • The data logger records on its own device, so a network failure cannot lose evidence.

Stage variation

Same in every stage; CAN logs in HIL and ViL.

Failure behavior

If recording fails, injection stops, since an unrecorded run cannot serve as evidence.
